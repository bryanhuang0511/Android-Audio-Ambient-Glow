## 🏗️ 為什麼採用多分支架構？ (Multi-Branch Architecture)

1. **極致輕量與純粹**：各平台使用者（Windows 玩家 vs Android 使用者）只需檢視與 Clone 他們所需的單一分支，不會下載到不相關平台的龐大二進制檔案或源代碼。
2. **獨立生命週期**：Rainmeter 皮膚腳本（`.ini` / `.lua`）與 Android 專案（Gradle / Kotlin）分開維護、互不干擾。
3. **清晰的首頁導覽**：`main` 主幹道保持簡潔純淨，專注為訪客提供直覺的索引地圖與即時跳轉。
