# 📱 手機音效氣氛燈 (Audio Ambient Glow) 開發交接與規格書

## 🎯 專案概述與目標
本專案旨在將已在 PC 端（Rainmeter 144Hz 滿版流光）驗證成功的**極致音訊動態跑馬燈流光演算法**，移植並開發為適用於 Android 行動裝置的**滿版懸浮邊框流光 App（手機音效氣氛燈）**。

---

## 💎 已在 PC 端驗證完成的核心視覺與物理演算法

### 1. 🌈 幾何與色彩連續性（防暈、無斷層演算法）
* **厚度 0% RGB 雜色原則**：
  * 邊框厚度（例如 16dp / 24dp）內部**色相絕對純色恆定**，只做單向向內的「高斯亮度/透明度羽化（Gaussian Inward Bloom）」，絕不在厚度方向產生彩虹漸層，避免視覺眩暈。
* **四角無縫閉環（4-Corner Closed Loop）**：
  * 頂邊、右邊、底邊、左邊四個轉角必須共用同一套頂點色相變數（$C_A \to C_B \to C_A \to C_B$ 或連續單圈 360° 跑道），轉角銜接處 100% 絕對同色對齊，零色階跳變。
* **賽道狂飆動力學（Perimeter Velocity & Acceleration Engine）**：
  * **基礎巡航速度**：平時保持均勻流暢的旋轉速度（約 0.5 ~ 0.8 圈/秒）。
  * **重低音瞬間爆發**：當感應到 Bass / 鼓點時，流光相位速度隨音量能量非線性激增（可加速至 3 ~ 5 圈/秒），音樂越炸、流光跑得越快！

### 2. ⚡ 音訊感應與快開快關（Smart Noise Gate & Fast Attack/Decay）
* **快開快關時間常數**：
  * **漸入（Attack）**：音樂播放或人聲響起時，於 **~0.9s** 內絲滑亮起。
  * **漸出（Decay）**：音樂暫停或結束時，於 **~1.1s** 內迅速降至全暗。
* **智慧防殘留雜訊門檻（Smart Noise Gate）**：
  * 設定音量底噪切斷閾值（Noise Gate Threshold），當音訊 RMS 振幅過低時直接 snap to 0，防止背景底噪導致流光殘亮。

## 🛠️ Android 手機端技術選型與架構規劃

### 1. 🖼️ 渲染層（高幀率滿版懸浮邊框）
* **實現方式**：
  * **方案 A（推薦：極致效能與圓角適配）**：Android `System Overlay Window`（`WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY`）+ `Custom SurfaceView` / `OpenGL ES Shader` / `Custom Canvas RenderNode`。
  * **方案 B**：Compose Multiplatform / Canvas 繪製路徑描邊，支援自適應圓角螢幕（DisplayCutout / Rounded Corners API）。
* **螢幕適配**：
  * 適配各廠牌打孔屏、水滴屏、動態島與大圓角半徑。
  * 支援 90Hz / 120Hz / 144Hz 高更新率流暢渲染。

### 2. 🎧 音訊感知層（Audio Capture）
* **Android 10+ 原生音訊捕獲**：
  * 使用 `AudioPlaybackCaptureConfiguration` API 或 `Visualizer` API（綁定 Session ID 0）即時提取系統與音樂播放器的音訊 FFT 頻譜。
* **頻段分割**：
  * **低頻（Sub-Bass & Bass，20Hz ~ 250Hz）**：驅動流光速度爆發與亮度震顫。
  * **中高頻（Mid & Treble，250Hz ~ 16kHz）**：驅動顏色色相推移與邊框微波擴散。
